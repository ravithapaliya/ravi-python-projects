Southern Piedmont Region; Cabarrus, Mecklenburg, Stanly and Union Counties; LiDAR; Classified Point Cloud
Tags  Model, LAS Point Cloud, Remote Sensing, Elevation Data, Withheld Bit Flag Proof of Performance, Swath Separation Imagery, Lidar, North Carolina, Southern Piedmont, Cabarrus County, Mecklenburg County, Union County, Stanly County

Summary
To acquire detailed surface elevation data for use in geospatial base mapping development. Classified LAS files are used to show the bare earth surface. The primary purpose of the lidar data was to produce orthoimages.
Description
This lidar data are processed Classified LAS 1.2 files, formatted into individual 10000 x 10000 ft tiles.  Geographic Extent: Southern Piedmont Region, Cabarrus, Mecklenburg, Stanly and Union Counties, including portions of adjoining counties, North Carolina, covering approximately 2,900 square miles. Dataset Description: Acquisition, processing and derivative products of lidar data to be collected at a +/- 10 points per square meter, nominal point spacing (NPS) of 0.1 meters. The data was developed based on a horizontal projection/datum of NAD83 (2011), North Carolina State Plane, and vertical datum of NAVD88 (GEOID18), US Survey Feet. Lidar data was obtained as flight line-extent unclassified LAS swaths, as processed Classified LAS 1.2 files, formatted into 10000 x 10000 ft tiles. Ground Conditions: Lidar was collected in December of 2022, and January, February and March of 2023, while no snow was on the ground and rivers were at or below normal levels. Spatial Data Consultants, Inc., established ground control points that were used to calibrate the lidar to known ground locations established throughout the project area. Additional independent checkpoints were used to assess the vertical accuracy of the data.

Process step ►
Description 
Boresight is performed at the beginning of the project period where a specific flight pattern is collected for a set of LIDAR flightlines. The objective is to align the output LIDAR data straight out of the point cloud processing software. This involves outputting the angular misalignment values between the IMU (INS subsystem) and the LIDAR sensor’s laser pointing. Using control points the boresight model is able to calculate the misalignment or boresight corrections. These 3 angles are put back into LMS and thus the output is aligned. The more-recent advancement is then using Bayes StripAlign software to remove any further misalignment within the data which can occur from several sources. The final product used (StripAlign point clouds) are thus the best fit datasets and are the source for data delivery.

Process step ►
When the process occurred 2023-04-25
Description 
LAS Point Classification: The point classification is performed as described below. Automated procedures were used to classify the bare earth surface, ASPRS Class 2 (Ground) points. All ground (ASPRS Class 2) lidar data inside water bodies over 1 acre were hydro-flattened but not classified as water (ASPRS Class 9). All overlap data was processed through automated functionality provided by TerraScan to classify the overlapping flight line data to approved classes. The overlap data was classified using standard LAS overlap bit. These classes were created through automated processes only and were not verified for classification accuracy. A cursory visual review of all the data was performed to remove obvious artifacts and misclassifications, however, a detailed visual review was not performed to remove every minor artifact or misclassification. TerraScan was used to create the deliverable industry-standard LAS files.
