Description:
Abstract:
This metadata document describes the LAS file containing 'bald earth' classification of LiDAR data masspoints collected by Kucera covering the project area of the County of Mecklenburg, NC.
Purpose:
The masspoints file depicts the 'bald earth' within the project area. All points not specifically derived from the terrain are removed (tree canopy, buildings, etc.). As such, the file is useful for a variety of applications, such as aiding in contour generation and the production of orthophotos.
Supplemental_Information:
This LiDAR point dataset is stored in a binary file format (LAS 1.0) specific to LiDAR data and includes all headers and attributes needed to create an ASCII or vector point file for use in a GIS. Headers and attributes are described in the 'Entities and Attributes' section in this metadata file. This dataset is partitioned into 5000' x 5000' tiles and the bounding coordinates in this file are for the project area extent, which is Mecklenburg county. The RAW point spacing of the LIDAR data is about 2 points per square meter, or an average spacing of 1.4M between any two neighbor points.

Data_Quality_Information:
Attribute_Accuracy:
Attribute_Accuracy_Report:
Attribute accuracy is tested in the LiDAR processing stage. After classification of the LiDAR data, the 'bald earth' point class is compared to ground control collected within the project area.
Logical_Consistency_Report:
Data was filtered using automated procedures followed by a manual review of the completed data set.
Completeness_Report:
LiDAR data is collected within the project area, processed and verified against control. The bare earth surface will contain voids where insufficient energy was reflected from the surface to generate a valid return from the terrain.

Process_Step:
Process_Description:
New LiDAR data is captured for the project area using a Leica ALS50 LiDAR instrument in conjunction with a POSAV Applanix GPS/INS system mounted within a Piper Navajo twin prop airplane. Base-station receivers are operated on the ground over known site points during the flyover to provide data necessary to reference the instrument position and orientation measurements to the terrain coordinate system. Altitude of flight was 5500' above mean terrain (AMT).

The airborne GPS/INS data is processed, in both forward and reverse directions, together with the simultaneously recorded ground-based GPS base station data to determine the LiDAR sensor's angle and orientation in the terrain (project) coordinate datum during the survey.

Attribute:
Attribute_Label: INTENSITY
Attribute_Definition:
Each return has an "intensity" value attributed to it, based on the brightness of the return. It is 8 bit, so the brightest return will have an intensity value of 255, the darkest a value of 0.
Attribute_Definition_Source: Kucera International Inc.

Each line flown in a mission is assigned a unique number. A flight line is defined as the time between activated recording and deactivated recording.
